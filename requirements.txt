# Пины env `silero` (pyenv, CPython 3.10), которым запускается play.sh. Не ставить в system python.
#
# Установка с нуля (полная команда, вместе с системными зависимостями — в play.md, раздел «Установка с нуля»):
#
#     python3.10 -m venv ~/.pyenv/versions/silero && ~/.pyenv/versions/silero/bin/python -m pip install \
#         --extra-index-url https://download.pytorch.org/whl/cu118 -r requirements.txt
#
# `--extra-index-url` обязателен: тегом `+cu118` собраны torch и torchaudio, на PyPI их нет —
# без этого флага разрешение зависимостей падает на torch==2.1.2+cu118.
# Ставить нужно именно python 3.10: под 3.11+ wheel `torch-2.1.2+cu118` не выпущен.
#
# Критично: num2words==0.5.14 (порядок падежей n/g/d/a/i/p).
# Проверка после установки: `python -m pip check` → «No broken requirements found»,
# `import torch; torch.cuda.is_available()` → True (GPU, CUDA 11.8).
#
# Состав снимка (pip freeze env `silero`, 41 пакет) и что из него нужно пайплайну — в play.md:
#   · нужды напрямую: silero, torch, torchaudio, soundfile, num2words (+ их транситивные зависимости);
#   · nvidia-cudnn-cu11 обязателен: из него берётся libcudnn.so.8, остальные библиотеки CUDA 11
#     уже вшиты в wheel torch (патченные sonames), поэтому `-cu11` пакетов всего три;
#   · блоки «CUDA 13» и «cuda-bindings» пайплайн не использует: это гора зависимостей пакета
#     cuda-bindings, который когда-то был поставлен в env. Удалить их нельзя, не сломав
#     `import nvidia.cudnn` в play.sh — подробности и разбор soname в play.md, раздел «Окружение».
